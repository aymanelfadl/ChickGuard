# AI Model Artifact Branch

This branch stores the trained poultry droppings image classification artifact
outside the main application source branch.

Files:

- `backend/app/ai_model/model/chicken_disease_model.keras.zip`
- `backend/app/ai_model/model/labels.json`
- `backend/app/ai_model/model/README.md`

To install the model into a checkout of `main`, copy these files into the same
paths, then unzip the model as described in `backend/app/ai_model/model/README.md`.
