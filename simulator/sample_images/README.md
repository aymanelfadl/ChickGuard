# Sample Images

Put local poultry images in this folder for image simulator mode.

Supported file types:

- `.jpg`
- `.jpeg`
- `.png`

Example:

```text
simulator/sample_images/chicken_01.jpg
```

Mock prediction label examples:

```text
healthy_01.jpg
coccidiosis_01.jpg
newcastle_01.jpg
salmonella_01.jpg
```
