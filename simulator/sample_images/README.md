# Sample Images

Put local poultry droppings images in this folder for image simulator mode.

Supported file types:

- `.jpg`
- `.jpeg`
- `.png`

Example:

```text
simulator/sample_images/healthy_droppings_01.jpg
```

Mock droppings analysis label examples:

```text
healthy_01.jpg
coccidiosis_01.jpg
newcastle_01.jpg
salmonella_01.jpg
```
